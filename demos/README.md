# Portal — демо карты разрешений

Отдельная страница на AntV X6. Все устройства и разрешения вымышлены; API, координатор и VPN не используются. Зависимости собираются локально, загрузки скриптов с CDN нет.

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://127.0.0.1:5173).

- Потяните от круглой точки на карточке к другой карточке и выберите разрешения. A → B означает, что A может подключаться к B.
- Клик по устройству открывает его сведения; клик по стрелке — изменение или удаление разрешения.
- Можно перемещать карточки, панорамировать поле и менять масштаб.
- «Выдать разрешение» и «Найти устройство» позволяют пользоваться диалогами с клавиатуры. Escape отменяет диалог и удаляет незавершённую стрелку.
- Устройства одного владельца имеют одинаковый цвет. Каждый из семи непустых наборов разрешений имеет свой постоянный цвет, независимо от порядка выбора.
- Позиции и разрешения сохраняются в localStorage этого браузера. «Восстановить пример» возвращает исходное демо.

«VPN-туннель» — условное разрешение для визуального прототипа по заданию; в основной системе WireGuard является транспортом, а реальные политики описывают TCP-доступ.

Проверка сборки: `npm run build`. Просмотр сборки: `npm run preview`.
