# Веб-интерфейс агента

`app.js`, `index.html` и `style.css` обслуживаются локальным API и встраиваются в Rust-бинарник через `include_str!`.

`xterm.js` также поставляется локально и встраивается в бинарник. Браузерный
терминал открывает одноразовый билет через HTTP и затем использует WebSocket
локального агента; CDN и координатор для потока терминала не используются.

Карта использует AntV X6 из `map-source.js`. Готовый `map.js` хранится в репозитории: для обычной сборки Rust Node.js не нужен. После изменения исходника карты:

```sh
cd runtime
npm ci
npm run build
```

Базовые стили X6 включены в конец `style.css`; автоматическая вставка CSS отключена для совместимости с CSP. Скрипты с CDN не загружаются.

Карта обновляется при получении снимка агента и реестра аккаунта. Желаемые политики собственных устройств перечитываются с координатора при каждом опросе (каждые 5 секунд). Неподтверждённая ревизия показана пунктиром. Изменение TCP-доступа через стрелку использует общий редактор политик и проверку ревизий. В редакторе terminal-разрешение задаётся отдельной галочкой, а TCP-порты вводятся текстовым списком через запятую. Позиции карточек сохраняются в localStorage отдельно для каждой сети; масштаб и позиции сохраняются при обновлении данных.

Отдельного присутствия и ОС в API нет: удалённая карточка показывает «Онлайн» при подтверждённом прямом пути, иначе «Офлайн». Данные о связях чужих удалённых устройств координатор текущему аккаунту не предоставляет.

Проверки:

```sh
python3 runtime/scripts/check-web.py
cargo check -p portal-runtime
```
