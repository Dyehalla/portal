Подключиться к клиенту

Откройте панель из установленного приложения Portal. Ссылка приложения подключает браузер к этому компьютеру автоматически.

Ссылку для входа можно получить командой sudo portal web. По умолчанию: /run/portal.token. Путь задаётся в настройке api_token_file агента.

Вход сохраняется при обновлении страницы в этой вкладке.
Выход из панели завершает сессию браузера. VPN продолжает работать.

Удалить устройство из сети

Устройство будет отозвано на координаторе. Его подключения перестанут работать после получения отзыва или истечения карты. Локальный профиль и аккаунт сохраняются.

Кто может подключаться к этому устройству

Выберите устройство и доступные ему сервисы внутри туннеля WireGuard. Обратный доступ задаётся отдельно.

Сам туннель WireGuard не требует отдельного разрешения в этом списке.

Применить разрешение ко всем моим устройствам

Разрешение заменит порты этого источника на каждом указанном устройстве. Остальные источники сохранятся. Сам источник исключён. Будущие устройства не наследуют разрешение. Черновик открытого редактора остаётся без изменений.
